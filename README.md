# Sven Wuyts - Developer Portfolio

Welkom bij de repository van mijn persoonlijke portfolio website. Deze website is gebouwd als eindproject voor de opleiding Programmeren aan Thomas More, maar is met dezelfde zorg opgebouwd als een professioneel product.

##  Live Demo
De website is live te bekijken op: [https://wuytssven.be](https://wuytssven.be)

##  Concept: "Cozy Terminal"
De website heeft een uniek design dat ik "Cozy Terminal" noem. Het combineert de warme, uitnodigende sfeer van een ouderwetse bibliotheek (met een perkament-kleurig kleurenpalet) met de technische precisie van een developer-omgeving.
*   **Typografie:** *Fraunces* (voor koppen), *Inter* (voor leesbare body tekst) en *Courier New* (voor de terminal-elementen en ASCII-kunst).
*   **Details:** Het ontwerp bevat diverse "Easter Eggs", zoals een slapende ASCII-kat in de footer die wakker wordt bij hover, en een kat in de hero-sectie die in slaap valt als je 20 seconden niets doet.
